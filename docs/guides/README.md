# Using the factory

[Documentation](../README.md)

Direct work through GitHub issue comments after [getting started](../getting-started/README.md). The configured owner gives the instructions; the bot reports the results.

| Topic | Use it to |
| --- | --- |
| [Workflow](workflow.md) | Choose Research, Plan, Implement, Validate, Spike or Bug. |
| [Working with issues](working-with-issues.md) | Write requests, refine stories and replan scope. |
| [Owner commands](owner-commands.md) | Find the exact comment commands and labels. |
| [Validation and delivery](validation-and-delivery.md) | Check finished work, then push, merge and close. |
| [Scheduling](scheduling.md) | Run work later, or after other work. |
| [Sync and conflicts](sync-and-conflicts.md) | Keep task branches current with the base branch and resolve conflicts. |
| [Attachments](attachments.md) | Give the agent images and documents. |
| [MCP](mcp.md) | Understand the factory tools an agent can call and how story creation is approved. |

For how the modes work inside, see the [workflow pages](../workflow/research-graph.md). For checking and repairing a stuck issue, see [Doctor](../operations/doctor.md).
