# T-100.3 — Direct scheduling controls and confirmations

> As an owner, I want immediate confirmation of scheduled work so that I know it was saved and when it will run.

This story turns valid scheduling comments into durable work without holding up later comments.

## Why This Matters

Scheduling is useful only when it is visible and does not freeze normal collaboration on the issue. Replies must remain safe and retries must not create duplicate visible outcomes.

## Architecture Notes

- Branch in daemon comment handling after authorization and before ordinary work dispatch.
- Persist idempotently, render structured confirmation/refusal, post it, then consume the control comment.
- Confirm direct/dependency schedule ID, resolved timing/rule, and outstanding count.
