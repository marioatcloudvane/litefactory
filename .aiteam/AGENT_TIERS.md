# Agent capability tiers

Current role tiers are authored in each role's frontmatter under `internal/teamsource/<workflow>`. Native delivery resolves them through `config.Tiers.ModelByTier` for the selected tool. `TestAgentTiersMatchCanonicalRoleFrontmatter` checks every canonical role against both configured tool maps; renderer and delivery fixtures verify native output. There is no independently maintained host-model table.

Former specialist assignments are recorded as migration evidence, not runtime role overrides: architect and requirements used flagship; code reviewer, implementation, unit testing, service testing, product owner and the retired orchestrators used balanced. Current graph role tiers, budgets and node keys are unchanged by consolidation.
