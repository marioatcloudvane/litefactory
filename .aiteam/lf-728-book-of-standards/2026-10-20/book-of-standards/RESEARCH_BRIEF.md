# Research brief

## Request

Establish the current integration points and boundaries for a stack-neutral Book of Standards: category/scope queries over MCP, MUST-based standards, CLI administration and CLI-invoked evidence-based agents for code/architecture drift, bugs/errors and logs.

## Decisions

- **d1** — The owner explicitly requests category-queryable MCP retrieval, a MUST-based standard format, CLI management and evidence-based standards agents. The supplied example is explicitly described as potentially excessive, so its fields are not a settled mandatory schema.
- **d2** — The issue requires stack-neutral support, identifiable standards versions per run, continued mandatory factory enforcement and avoidance of conflicting migrated copies. This research pass does not authorize implementation or publication.


## Assumptions

- **a1** — Treat code/architecture drift, bugs/errors and log analysis as three evidence use cases. Whether they share one agent or have separate roles is a shaping decision; the owner has not fixed their implementation topology.
- **a2** — Treat generated-standard publication policy as unresolved: the owner says the drift agent suggests standards and the bug agent adds them. Research does not equate either wording with settled unrestricted publishing authority.
- **a3** — Treat categories, scope filters, rule identifiers and MUST wording as required concepts. The sample does not settle field requiredness, category hierarchy, matching semantics, exception handling or ownership defaults.
- **a4** — The bounded inspection located existing integration points and candidate instruction families, not a complete semantic inventory of every graph extra or a verified mapping to issue #649. The supplied issue and owner comment are the requirements evidence; no external issue history was fetched.
- **a5** — Storage location, deployment topology, access model, editing/version lifecycle, run pinning, query triggers, unavailable-service behavior, evidence time window and historical bug source remain shaping decisions. Existing capture behavior is a reuse precedent, not a selected design.
- **a6** — No standards catalogue or dedicated standards-mining agent was located in the inspected command registration, MCP guide and role inventory. This is bounded search evidence rather than proof that no adjacent code exists elsewhere. No authentic historical drift/bug/log corpus was evaluated and no effectiveness claims are made.
