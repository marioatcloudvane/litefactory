# React, TypeScript and Vite guidance
React 19.3 and Vite 8.3 use the exact TypeScript, plugin and check-tool pins in supported-versions.md. TypeScript must use strict checking; do not silence boundary errors with any or unsafe assertions. Run the required typecheck, lint, test and build scripts; missing scripts or tests fail.

Use typed API access based on backend OpenAPI request/response and error contracts. Follow the repository's client generation convention rather than adding a generator. Handle loading, empty, error and success states explicitly; cancel stale requests and respect component lifetimes. Do not expose tokens in logs or frontend bundles.

Prefer accessible semantic elements, labels, keyboard interactions and visible focus. Keep state local where practical and follow existing routing and state conventions. Test components with Vitest and Testing Library through observable user interactions, including loading/error states and accessibility. Use the repository's DOM test environment and avoid pass-with-no-tests.

Use the Vite production build as a required check. Follow existing authentication, persistence and deployment conventions; this team does not choose infrastructure or scaffold an example application.
