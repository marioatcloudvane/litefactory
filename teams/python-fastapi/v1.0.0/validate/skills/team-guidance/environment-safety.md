# Test environment safety

For repositories that authorize tests against a running service, establish the test or staging URL and a dedicated test database before any run. TEST_BASE_URL must be set for those tests and must not point at production. TEST_DATABASE_URL must be set when a real external test database is required. Missing or ambiguous environment evidence means refuse the run and explain what is missing. Never test against production, weaken permission checks or expose credentials in reports.

This retains the safety intent of the former pre-tool hook. It installs no executable hook and grants no service access. Litefactory has no integration tags or separate integration-test convention: use its existing offline fixtures, temporary databases and in-process test servers. Paid provider calls and authentic host observations require separate authorization; synthetic fixtures cannot substitute for them.
