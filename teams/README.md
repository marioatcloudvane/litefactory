# Team distribution

The catalogue and current `go-development/v1.1.0` release are generated from
`internal/teamsource` by `go run ./cmd/teamrelease`. Do not edit them. Check drift
with `go run ./cmd/teamrelease -check`.

`go-development/v1` is the immutable pre-consolidation release kept for historical
capture and compatibility fixtures. It is not a current authoring source. Saved
runs retain those original bytes, builtin identity and hashes.
