Apply to browser-based Blazor work. Use the bundled compatibility, practices and
recipe contracts throughout Research, Plan, Implement, setup and checks. Default
new Blazor Web App work to Interactive Server; preserve existing repository choices.
No application database, authentication provider, component library or deployment
platform is implied. Blazor Hybrid/MAUI and older .NET versions are outside this
release. Keep the selected shared workflow gates and read-only Validate.
