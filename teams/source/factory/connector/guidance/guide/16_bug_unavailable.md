## Filing a bug is not available here

This connection cannot file bugs. Say that plainly. Do not try to file a bug through a feature request or any other route, and do not invent one. The owner can file the bug on the project's issue tracker directly, or reconnect the connector and tick any consent scope the scopes section lists as missing. If it lists none, this installation does not offer bug filing. You can still help write a clear description: expected, actual, steps and evidence.
