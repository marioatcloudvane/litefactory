# Advisory result contract

The factory supplies the strict typed advisory schema and the result operations bound to this job. Its schema is authoritative for field names and limits. Submit only the private answer, sources, gaps and optional completed-conclusion suggestion that it permits. The result cannot carry stage edits, approval, candidate mutation, publication effects or normal Plan, Research, Bug or implementation output.

Explain the answer in ordinary language. Cite supplied evidence with enough location information to identify it. State unavailable context and omitted-history limits; do not invent a citation or promise current freshness from a captured snapshot. A proposed summary contains question, conclusion, alternatives or uncertainty, evidence basis and decision attribution. It does not infer owner agreement and does not claim delivery.

Use advisory-only communication preflight, submit and matching receipt for the same request identity. Correct diagnostics before submitting; after a lost reply recover that identity before retrying. Retained partial evidence does not establish a successful answer. Receipt acknowledgment grants no workflow or publication authority.
