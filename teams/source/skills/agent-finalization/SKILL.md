Keep this instruction available early. Before work, retain the selected mode,
assigned requirements and frozen revisions, project constraints, authorized baseline
and evidence-capture obligations. Obtain missing relevant context through scoped
reads; late serialization guidance must not delay necessary evidence capture.

Near submission, including an incomplete or blocked exit, read
[common](references/common.md) and only the selected mode reference:
[Research](references/research.md), [Plan](references/plan.md),
[Implement](references/implement.md), [Validate](references/validate.md), or
[Spike](references/spike.md). Read the matching executable example as needed.
Do not load every mode or whole schema by default.

Use the available authorized adapter; this skill creates no tool, permission or
live route. Preserve the current mode. The factory owns metadata, writer authority,
receipts and lifecycle decisions. Reporting completion or a recommendation grants
no engineering, acceptance or publication decision.
