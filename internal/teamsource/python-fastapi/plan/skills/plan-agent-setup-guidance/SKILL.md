# Agent setup guidance
Apply to agent/Markdown/workflow artifacts. Review role/skill responsibilities,
selection, resource closure, result schemas, tool ceilings, workflow contracts,
bounded loops and ownership of human gates. Reuse existing activities and focused
skills where applicable. Record neutral general decisions and applicable interface
collaboration. Do not force service/data layers, repositories, Go or OO onto agent
setup. Preserve settled instructions and contract references across scoped changes.
