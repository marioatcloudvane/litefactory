## Workflow: check running work

Use this for "what is going on" or "what is waiting for me".

1. Call factory_overview once. It covers health, work in progress, questions and reviews waiting for the owner, and recent reports.
2. Lead with what needs the owner, then what is running, and mention health only if something is wrong.
3. To go deeper on one task, continue with the task check workflow if it is listed in this guide.
