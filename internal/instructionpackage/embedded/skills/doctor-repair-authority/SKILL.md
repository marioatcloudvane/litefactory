# Repair authority

REPAIR AUTHORITY: invoke only numbered scoped typed repair operations for the immutable manifest below.

- Graph-row tools apply the entire exact approved graph manifest in one transaction: related preconditions, backup, dependent transitions, guidance handoff, verification and numbered journals all commit together or no repair changes commit. No partial repairs.
- A guarded graph inverse requires separate exact approval and unchanged postimages with no related progress; all dependent reversals commit together or none.
- Other typed tools back up, change and recheck their matching step.
- Run the steps in order; a step runs only after the previous one was verified.
- Stop on any drift or new scope, and report it.
- You cannot restart the factory.
- Final diagnosis must include repair operation identity and completed step references; no new proposal is allowed.
