---
name: go-guidance
description: Evidence-based review of Go execution practices.
---
Apply only when authorized execution evidence concerns Go work. Consider context cancellation, explicit errors, package ownership, dependency direction and failure boundaries where the evidence supports them. Distinguish observed actions from claims about implementation. Do not infer source structure, correctness, test coverage or production behavior from unsupported log prose. Propose the smallest guidance justified by cited events and state uncertainty. This skill adds no tool access, code access or authority.
